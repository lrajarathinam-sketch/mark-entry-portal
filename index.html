Quick Setup Guide (Google Cloud Console):
  1. Open console.cloud.google.com and create a project (e.g., GGHSS-Mark-Portal).
  2. Go to APIs & Services → Library, search Google Drive API, and click Enable.
  3. Go to Google Auth Platform / OAuth consent screen → choose External, enter your email, and add your Gmail under Test users.
  4. Go to Credentials → + Create Credentials → OAuth client ID → Web application.
  5. Under Authorized JavaScript origins, add your site URL (e.g., https://yourusername.github.io).
  6. Copy the generated Client ID, paste it above, and click Save Client ID.
